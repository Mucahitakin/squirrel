Proje klasörü

Test edeceğin herhangi bir projenin klasörü. Squirrel orada dataset'leri (datasets/) ve projenin kendi test betiğini (squirrel.harness.* ya da seçtiğin betik) bulur. İsteğe bağlı: seçmezsen Squirrel kendi dataset'leriyle bağımsız çalışır; Chat API motoru ve SDK her durumda çalışır.

Canlı yansıtma

Açıkken SDK/üretim verisi geldiği an arayüze düşer (SSE); kapalıyken sayfayı yenilediğinde görünür.

Sonuç klasörü

Kod ile entegrasyon (squirrel-trace SDK)

Başka uygulamalar bu anahtar ile Squirrel'e koşu/tur gönderebilir; kayıtlar Koşular ve Monitoring'de görünür. SDK: Squirrel/sdk klasörü (npm'e yayınlanabilir).

import Squirrel from 'squirrel-trace';
const sq = new Squirrel({ apiKey: 'ANAHTAR', project: 'uygulamam' });
const run = sq.startRun();
const turn = run.turn({ input: 'kullanıcı mesajı', thread: 'sohbet-1' });
turn.tool('web.search').usage({ input: 1200, output: 240 });
await turn.end({ output: 'asistan cevabı' });
